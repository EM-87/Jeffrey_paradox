# Our own English for messages the GameCube's script has no counterpart for, in tools/msgbank.py's
# dump form: a header line with the message's number, the message with its control codes as <NAME hex>,
# and notes on lines that start with "#:". make script lays every script/message/*.txt over the draft by
# number; make rom-en lays them over the compiled bank as well, after the 2010 patch's messages.
#
# A message here keeps every code of the cartridge's that steers the game (how it ends, its choices,
# the messages that follow, the talk orders, sounds and luck) in the cartridge's order, and prints no
# string the game does not fill for it: af_text.py checks both against the user's dump. Pauses, colours,
# text scale and page breaks are the English's; a colour's count (COLORCHARS' last byte) is the number
# of English characters it colours. The en build's own string codes (CAPTIALIZE, CUTARTICLE, STR_AMPM)
# may be added: they only shape a string the message prints.
#
# The 2010 patch has these 45 messages in English with codes of its own (NOTES, "The 2010 patch's
# messages"); this text is ours, translated from the cartridge's.
