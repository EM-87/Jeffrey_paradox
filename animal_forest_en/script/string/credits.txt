# The staff credits (1258-1364) in English: the cartridge's list, line for line. The GameCube's string
# bank has its own staff at these numbers (other people, another order), which the draft took by number;
# the cartridge's credits are drawn by the orange box (ovl_Mikanbox: func_80AA3D08_jp loads ten lines of
# 15 bytes from string 1258 + a page's first line, D_80AA4D54_jp, sixteen pages; func_80AA3D94_jp draws
# them from x 150, a page's first line and the lines in D_80AA4D68/69_jp smaller: the job titles). So a
# line here is at most 15 bytes, a title where the cartridge has a title, a name where it has a name, a
# blank where it has one; a name longer than 15 is written with its given name's initial. Names in the
# order English credits use (given name first). tools/msgbank.py's dump form; `make script` lays this over
# the string draft by number.
