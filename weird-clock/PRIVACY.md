# Weird Clock — Privacy Policy / Política de privacidad

_Last updated / Última actualización: 2026-07-18_

## English

**Weird Clock does not collect, store, or transmit any personal data.**

- **No network access.** The app makes no network requests. Nothing you do
  in the app ever leaves your device.
- **Location** (optional): if you enable *Sun time*, the app reads one
  coarse location fix to compute your longitude. It is used only to shift
  the displayed time to local apparent solar time, is cached on your
  device, and is never transmitted anywhere.
- **Sensors**: the accelerometer is read only while the app is open, to
  power the knock-the-hands-off physics and the hourglass flip. Readings
  are used in the moment and never stored.
- **Custom alarm sounds**: if you pick an audio file for an alarm, the app
  keeps a read permission for that file so the alarm can play it. The file
  itself is never copied or uploaded.
- **Overlay permission** (optional): used exclusively to draw the floating
  hourglass while a countdown runs.
- **No analytics, no ads, no third-party SDKs, no accounts.**

## Español

**Weird Clock no recoge, almacena ni transmite ningún dato personal.**

- **Sin acceso a la red.** La app no hace ninguna petición de red. Nada de
  lo que hagas en la app sale de tu dispositivo.
- **Ubicación** (opcional): si activas la *Hora del sol*, la app lee una
  ubicación aproximada para calcular tu longitud. Solo se usa para
  desplazar la hora mostrada a la hora solar aparente local, se guarda en
  tu dispositivo y no se transmite a ninguna parte.
- **Sensores**: el acelerómetro se lee solo con la app abierta, para las
  físicas de derribar las manecillas y el volteo del reloj de arena. Las
  lecturas se usan al momento y no se almacenan.
- **Sonidos de alarma propios**: si eliges un archivo de audio para una
  alarma, la app conserva un permiso de lectura sobre ese archivo para
  poder reproducirlo. El archivo nunca se copia ni se sube.
- **Permiso de superposición** (opcional): se usa exclusivamente para
  dibujar el reloj de arena flotante mientras corre una cuenta atrás.
- **Sin analíticas, sin anuncios, sin SDK de terceros, sin cuentas.**
